# Начало

Сперва указываем всё в config.py потом запускает контейнер!


# Запуск скрипта 
```
docker build -t bs2_parser .
```
```
docker rm -f bs2_parser || true
```
# на винде
```
docker run -d --name bs2_parser --restart=always bs2_parser
```
# когда ставим на линуксе, монтируем папку, чтобы логи сохранялись в корень проекта
```
docker run -d --name bs2_parser --restart=always -v /home/bs2_parser:/home/bs2_parser bs2_parser
```
# Настройка скрипта config.py

`BASE_URL` - Зеркала Ссылку указывем без / в конце

`HOST` - Куда будем отсылать данные

`LOGIN`  - логин к сайту 

`PASSWORD` - пароль к сайту 

`RUCAPTCHA_API_KEY` - Апи ключ от рукапчи

`DB_NAME` - Название базы данных

`MANUAL` - Параметр для ввода капчи вручную. True - вручную. Если запускаем вручную. False - Автоматически через рукапчу. Если запускаем на сервер. В папку images будут сохраняться капчи при ручном вводе

`REVIEWS_AMOUNT` - Так как на один магазин по 4к отзывов доходить может, то чтобы не ломать сайт и чтобы был меньше шанс забанить скрипт, указываем количество страниц отзывов которые мы будем парсить на магазин.

# Описание проекта 
`proxies.txt` - Там указывается прокси. Только HTTPv4. Вставлять без пустых строк, иначе не будет работать.

`main.py `- главная логика парсинга

`cookie.py` - главная логика авторизации на сайте и получение 
куки.

`sender.py` - механизм отправки сообщений из БД на эндпоинт. Работает в цикле. Запускается раз в 24 часа.

## Описание структуры БД:

# Таблица exchanges
`name` - TEXT  название обменника (⚡️МОМЕНТАЛЬНЫЙ ОБМЕН 24/7⚡️)

`link` - TEXT ссылка на обменник (https://blacksprut-net.ru/exchanges/10) 

`directions` - TEXT направления пополнения (VISA/MASTERCARD / Процент: 29 % SBP / Процент: 29 %)

`deposite` - TEXT депозит в биткоинах (0.09150021 ₿)

`reviews` - JSON массив отзывов со следующей структурой
```
{
    'nickname' - TEXT ник комментатора
    'comment_text' - TEXT текст коментария
    'purchases' - INT количество покупок комментатора.
    'datе' - TIMESTAMP WITHOUT TIMEZONE время комнентария
    'img' - TEXT ссылка на аватарку комментатора
    'admin - BOOL ответил ли админ
    'rating' - TEXT рейтинг комментатора.
}
```

# Таблица stores
`name` - TEXT  название магазина (X-LAB V.2.0 РЕАНИМАЦИЯ)

`link` - TEXT ссылка на магазин (https://blacksprut-net.ru/stores/76) 

`sales` - TEXT количество продаж магазина

`deposite` - TEXT - депозит магазина(0.02466762) 

`rating` - Float райтинг магазина (4.5) 

`rules` - TEXT текст с правилами магазина 

`vacancy` - TEXT текст с вакансиями магазина 

`promotions` - TEXT текст с акциями магазина 

`products` - JSON витрина магазина со следующей структурой
```
{
    "name" - TEXT название магазина
    "link"- TEXT ссылка на продукт
    "description" - TEXT описание продукта
    "price" - TEXT цена в рублях (3000) 
    "price_btc" - TEXT цена в биткоинах (0.00031787) 
    "unit" - TEXT Единица товара
    "img_link" - TEXT ссылка на изображение продукта без домена (/storage/products/49496/05T53gYMA1JUwBD1MHMsgGJNqcurf9uulO6dL4g4.jpg)
}
```
